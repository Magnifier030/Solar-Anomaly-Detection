IoU 的分式分別為 `7525 / 209821` 和 `0 / 204425`。官方 F1_TIoU 並非直接套用像素 TP/FP/FN：預訓練的加權 recall 為 `0.1343995762 / 190 = 0.0007073662`，加權 precision 為 `3.9526702047 / 329 = 0.0120141952`，再取 harmonic mean。微調的 recall 為 `0 / 190`；沒有預測物件，precision 分母為 0，依現有 evaluator 定義 precision=0，F1=0，不執行 0/0 除法。

所有 GT 正樣本位於 G02（197 張）；G05（11 張）、G08（7 張）均無 GT 前景。預訓練在 G02 的 TP/FP/FN 為 7525/5317/196900，G05 有 79 個誤報像素，G08 無預測前景。微調在三個 group 都無預測前景。

門檻由 0.5 降至 0.05 時，預訓練 IoU 只有 0.036588210，微調仍為 0；微調整個驗證集的最大預測機率僅 0.00007644185。因此不是分母過大導致顯示四捨五入成 0，而是微調快照確實將驗證集全判背景。另在 8 張訓練正樣本抽查有約 0.8835 的 global pixel IoU，該數字僅為抽查，不能當完整訓練集分數。這支持「訓練／驗證落差」的現象，但尚不能區分尺度、場景、BN 統計或最佳化等個別原因。

預訓練對外部框 mask 的 0.5991 IoU 不能直接當成競賽表現；直接遷移只抓到少部分區域，與整片模組標註存在差異。現階段不宜只增加 epochs 或只調 threshold 期待解決，應進一步檢查逐圖預測與不同 group 的行為。
